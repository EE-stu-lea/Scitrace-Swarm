# SciTrace-Swarm 提交说明

入口为 `code/examples/scitrace_research/run_submission.ps1`。系统要求 Python 3.11、项目虚拟环境依赖、可访问的 OpenAI 兼容模型接口，以及 OpenAlex/Crossref 网络访问。

运行前设置 `API_BASE`、`API_KEY`、`MODEL_NAME`、`MODEL_PROVIDER`。脚本运行 native Team strict-real 流程，通过一致性门禁后生成英文 ICLR PDF。传入 `-AccessToken` 时，脚本继续验证外部材料并构建以正式队名命名的比赛 ZIP；已有公开 PR 时可额外传入 `-PrUrl`。

`Agentic Reviewer/PaperReview-AccessToken.txt` 必须是对包内同一份 `paper/paper.pdf` 的评测 Token；样例 Token 不可复用。运行证据位于 `artifacts/`，包括 manifest、模型调用记录、Team handoff、文献元数据、实验结果、Claim、审计日志和资源报告。`submission_manifest.json` 保存文件大小与 SHA-256，用于检查 ZIP 内容未被意外替换。
