# Innovation

1. **Evidence Graph as shared Team state.** Stable identifiers and typed provenance edges connect literature, executable artifacts, claims, and revisions across independent Agent sessions.
2. **Lifecycle rails for scientific work.** Provenance capture, stage-aware context selection, consistency checking, and resource auditing are reusable JiuwenSwarm rails rather than prompt-only conventions.
3. **Separation of design and execution.** The Experiment Agent reviews hypotheses, controls, metrics, and limitations; only a trusted script can run, so model output cannot silently fabricate code or results.
4. **Executable claim gate.** Numeric statements are checked against a hashed `results.json`; invalid drafts enter bounded targeted revision and cannot be reported as successful.
5. **Strict-real acceptance.** The manifest records real model and literature calls and rejects mock or fixture fallback in competition runs.
